**3 Термина́ны, опре́де́ления и обозначения**

**3.1 Термина́ны и опре́де́ления**

В настоящих рекомендациях применены следующие терми́ны с соответсво́вущими опре́де́лениям:

- **эмитент**: Банк, выпусший платежну́ю карту;
- **держатель карты**: Лицо, на имя кото́рого выпусшну платажну́ю карту.

**3.2 Обозначения**

В настоящих рекомендациях используются следующие обозначения:

- $V_n$ — конте́жномерное векторное пространство размерснсти $n$;
- $A||B$ — конте́натсия строков, т. е. если $A \in V_{n1}, B \in V_{n2}$, $A=(a_{n1-1}, a_{n1-2}, ..., a_0)$, $B=(b_{n2-1}, b_{n2-2}, ..., b_0)$, то $A||B = (a_{n1-1}, a_{n1-2}, ..., a_0, b_{n2-1}, b_{n2-2}, ..., b_0) \in V_{n1+n2}$;
- $\oplus$ — дополне́ние десятчли́ми нулями последовате́лности до тех пор, пока ее дли́на не станет равной 16;
- **CVK**: ключа́рь карты для вычисления CVP при эмиссии карт и прове́рке транса́кций по магнитно-полосе (для вычешления CVP при эмиссии карт и прове́рке транса́кций по магнитно-полосе в электрио́нном виде в базе данных БД хоста эмитента. Длина значе́ния равна 32 байтам);
- **CVP**: прове́рочный параметр платежну́ю карты (Card Verificátion Parameter). Длина значе́ния равна трех десятчли́м цифрам;
- **CVP2**: прове́рочный параметр карты, который размещен на оборотно́й стороне карты и использо́ван для выполне́ния платежну́ю операций без предвярежения карт (вычешления аналогично вычешлению CVP). Длина значе́ния равна трех десятчли́м цифрам;
- **$E_K(M)$** — функсшя́р шифрова́ния;
- **iCVP**: функсшя́р шифрова́ния, который размещен на чипе карты в составе track2. Прове́рочный данн и использо́ван при прове́рке транса́кций по чиповым картм в моде магнитно-полосе (вычешления аналогично вычешлению CVP). Длина значе́ния равна трех десятчли́м цифрам;
- **PAN**: номер карты (Primary Account Number). Длина значе́ния рав от 12 до 20 десятчли́м цифр;
- **PAN\_11**: последне́ние 11 десятчли́м цифра PAN, исключаю прове́рочный симбол;
- **PAN\_16**: перве́вые 16 десятчли́м цифра PAN. Если значе́ние PAN менее 16, то дополне́ется нулями. Длина значе́ния равна 16 десятчли́м цифрам;
- **PIN**: персо́на́льный идентифициро́вншй номер (Personal identification number). Длина значе́ния рав от 4 до 12 десятчли́м цифр;
- **PIN\_4**: четве́ре перве́ые десятчли́м цифра PIN;
- **PVK**: ключа́рь карты для вычисления PVV при эмиссии карт и прове́рке транса́кций по магнитно-полосе. Ключ генерируетс в HSM с помошю FDCС и хранитс в зашифрованном виде в БД хоста эмитента. Длина значе́ния равна 32 байтам;
- **PVKI**: индекс ключа прове́рки PIN (PIN verification key index). Цифра в интервале 0 ... 6;
- **PVV**: прове́рочное значе́ние PIN (PIN Verificátion Value). Длина значе́ния равна четве́рем десятчли́м цифрам;
- **SVC**: сервисншй код (Service code). Длина значе́ния равна трех десятчли́м цифрам;
- **YUMM**: срок дейстия карты. Длина значе́ния равна четве́рем десятчли́м цифрами, причем перве́вые две цифры соответсвоуют году, а два после́дние — месяцу.

4.2 Алгоритм формирования проверяющего значения PIN (PVV)

Для вычисления PVV последовательность $(PAN_{11}\|PVK\|\|PIN_4)$, состоящая из шестнадцатеричных символов, зашифровывается с помощью алгоритма шифрования ГОСТ 28147—89 в режиме простой замены с узлом замены id-tc26-gost-28147-param-Z с использованием ключа PVK.

Полученная двойная последовательность интерпретируется как натуральное число. Значение PVV полагается равным остатку от деления данного числа на 10 000. Соответствие между двойной последовательностью и натуральным числом задаётся естественным образом.

Все числовые значения приведены в десятичной или шестнадцатеричной записи. Нижний индекс в записи числа обозначает основание системы счисления. Представление числа из десятичной системы счисления в шестнадцатарную систему счисления происходит по следующему правилу: каждая цифра десятичного числа переводится в одну цифру шестнадцатарного числа. Например, целое число 123456789₁₀ представляется в шестнадцатаричном виде, как число 123456789₆. Соответствие между десятичными и шестнадцатеричными цифрами задаётся естественным образом (таблица А.1).

В данном приложении A.1 двоячные строки из V*, длина которых кратна 4, записаны в шестнадцатаричном виде, а символ конкатенации («||») опускают. То есть строка a ∈ V₄ᵣ будет представлена в виде a_{r-1}a_{r-2}...a₀, где a_i ∈ {0, 1, ..., 9, a, b, c, d, e, f}, i = 0, 1, ..., r-1. Соответствие между двоичными строками длины 4 и шестнадцатаричными строками длины 1 задается естественным образом (таблица А.1).

Преобразование, ставшее в соответствие двоичной строке длины 4r шестнадцатаричную строку длины r, и соответствующее обратное преобразование для простоты записи опускают.
