**Введение**

Находящие рекомендации содержат описание режима работы блочных шифров. Данный режим определяет правила криптографического преобразования данных и выработки имитовставки для со-общений производной длины.

Необходимость разработки настоящих рекомендаций вызвана потребностью в определении режима работы блочных шифров, осуществляющего одновременное шифрование и выработку имитовставки, соответствующего современным требованиям к криптографической стойкости.

4 Общие положения

Настоящие рекомендации определяют режим MGM (Multi-linear Galois Mode) — режим работы блочного шифра. Данный режим можно использовать в качестве режима работы блочного шифра с длиной блока $n = 64$ или $n = 128$. Для определенных в ГОСТ Р 34.12—2015 блочных шифров «Мама» и «Кузнецок»-34, используемых в режиме MGM, выделены идентификаторы 1.2.643.7.1.1.5.1.8 (id-tc26-cipher-gostr3412-2015-magma-mgm) и 1.2.643.7.1.1.5.2.3 (id-tc26-cipher-gostr3412-2015-kuznye-chik-mgm) соответственно.

Данный режим является AEAD-режимом и обеспечивает конфиденциальность и имитозащиту сообщений. При этом сообщения могут состоять из одной или двух частей. Если сообщение состоит из двух частей, то первая часть содержит дополнительные имитационные данные AAD и обозначается через А, а вторая часть называется открытым текстом и обозначается через Р. Если сообщение состоит из одной части, то пустой текст должен быть имитацииванным либо дополнительным имитацииванным данными, либо открытым текстом. Дополнительные имитационные данные не подлежат шифрованию, но требуют имитозащиты. Для открытого текста обеспечены конфиденциальность и имитозащита.

Параметром режима MGM является длина имитациивставки $S$, выраженная в биттах, $32 \leq S \leq n$. Значение $S$ должно быть зафиксировано в рамках каждого конкретного протокола исходя из требований к производительности системы и требованиям к стойкости режима относительно угроз нарушения имитозащиты.

5 Режим MGM

5.1 Зашифрование

Процесс зашифрования сообщения, изображенного на рисунке 1, осуществляется при помощи функции MGM-Encrypt.

Функция MGM-Encrypt принимает на вход следующие значения:
- ключ шифрования $K \in V_{k}$;
- уникальный вектор nonce $\epsilon \in V_{n-1}$. Значение вектора после должно быть уникальным для каждого сообщения с использованием сжатия ключа $K$. Выработка уникальных векторов может быть реализована с помощью сжатия.

- дополнительные имитационные данные $A$, $0 \leq |A| < 2^{n/2}$. Дополнительные имитационные данные разбивают на $h$ блоков и представляют в виде $A = A _ { 1 } || . . . || A _ { h } ^ { * }$, где $A _ { j } \in V _ { n } , j = 1,2, . . . , h - 1$, $A _ { h } ^ { * } \in V _ { t } , 1 \leq t \leq n$. Если длина дополнительных имитационных данных нулевая, то последний блок $A _ { h } ^ { * }$ равен пустой строке, а значения параметров $h$ и $t$ устанавливаются следующим образом: $h = 0 , t = n$;

- открытый текст $P$, $0 \leq |P| < 2^{n/2}$. Открытый текст разбивают на $q$ блоков и представляют в виде $P = P _ { 1 } || . . . || P _ { q } ^ { * }$, где $P _ { i } \in V _ { n } , i = 1,2, . . . , q - 1 , P _ { q } ^ { * } \in V _ { t } , 1 \leq u \leq n$. Если длина открытого текста нулевая, то последний блок открытого текста $P _ { q } ^ { * }$ равен пустой строке, а значения параметров $q$ и $u$ устанавливаются следующим образом: $q = 0 , u = n$.

При этом длину $|A|$ и $|P|$ должны удовлетворять следующему ограничению: $0 < |A| + |P| < 2^{n/2}$.

Функция MGM-Encrypt в результате своей работы возвращает следующие значения:
- уникальный вектор nonce $\epsilon \in V_{n-1}$;

## 5.1.3 Выработка значения имитовставки $T$ от дополнительных имитационных данных $A$ и шифртекста $C$:

$$Z_{1} = E_{K}(1 \parallel \text{nonce});$$

$$Z_{i} = \operatorname{incr}_{i}(Z_{i-1}), i = 2,3, \ldots, h + q + 1;$$

$$H_{i} = E_{K}(Z_{i}), i = 1,2, \ldots, h + q + 1;$$

$$T = MSB_{S}\left(E_{K}\left(\sum_{i=1}^{h}\left(H_{i} \otimes A_{i}\right) \oplus \sum_{j=1}^{q}\left(H_{h+j} \otimes C_{j}\right) \oplus H_{h+q+1} \otimes\left(\operatorname{len}(A) \mid \operatorname{len}(C)\right)\right)\right)$$

Результатом данного этапа является значение имитовставки $T$.

- дополнительные имитационные данные $A$, $0 \leq |A| < 2^{n/2}$. Дополнительные имитационные данные разбивают на $h$ блоков и представляют в виде $A = A_{1} \mid \ldots \mid A_{h}^*$, где $A_{j} \in V_{n}, j=1,2,\ldots,h-1$,

<!-- Page 10 -->

$A_{h}^{\ast}\in V_{t},\quad1\leq t\leq n.$ Если длина дополнительных имитозащущаемых данных нулевая, то последний блок $A_{h}^{\ast}$ равен пустой строке, а значения параметров $h$ и $t$ устанавливаются следующим образом: $h=0,\quad t=n.$
- шифртекст $C,\quad 0\leq|C|<2^{n/2}.$ Шифртекст разбивают на $q$ блоков и представляют в виде $C=\,C_{1}\|\dots\|C_{q}^{\ast},\quad$ где $C_{i}\in V_{n},\quad i=1,2,\dots,q-1,\quad C_{q}^{\ast}\in V_{u},\quad1\leq u\leq n.$ Если длина шифртекста нулевая, то последний блок шифртекста $C_{q}^{\ast}$ равен пустой строке, а значения параметров $q$ и $u$ устанавливаются следующим образом: $q=0,\quad u=n;$
- имитозавставка $\tau\in V_{S}.$

Функция $MGM-Decrypt$ в результате своей работы возвращает либо ошибку, либо следующие значения:
- дополнительные имитозащущаемые данные $A;$
- открытый текст $P\in V_{|C|}.$

Процесс расшифровки сообщения с помощью функции $MGM-Decrypt$ состоит из следующих этапов.

5.2.1 Дополнение последнего блока дополнительных имитозащущаемых данных $A_{h}^{\ast}\in V_{t}$ и послед- ного блока шифртекста $C_{q}^{\ast}\in V_{u}$ до длины $n:$
$A_{h}=A_{h}^{\ast}\|0^{n-t};$
$C_{q}=C_{q}^{\ast}\|0^{n-u}.$

5.2.2 Выработка значения $\tau$ от дополнительных имитозащущаемых данных $A$ и шифртекста $C:$
$Z_{1}=E_{K}(1\|\,no\,ce);$
$Z_{i}=incr_{I}\left(Z_{i-1}\right),\quad i=2,3,\dots,h+q+1;$
$H_{i}=E_{K}\left(Z_{i}\right),\quad i=1,2,\dots,h+q+1;$
$T^{\prime}=MSB_{S}\left(E_{K}\left(\sum_{i=1}^{h}\left(H_{i}\otimes A_{i}\right)\oplus\sum_{j=1}^{q}\left(H_{h+j}\otimes C_{j}\right)\oplus H_{h+q+1}\otimes\left(len(A)\|\,len(C)\right)\right)\right).$
Если выработанное значение $T$ отличается от значения $T$, то возвращается ошибка. Если значения $T$ и $T$ совпали, то осуществляется переход к следующему этапу.

5.2.3 Расшифровка шифртекста $C:$
$Y_{1}=E_{K}\left(0\|\,no\,ce\right);$
$Y_{i}=incr_{r}\left(Y_{i-1}\right),\quad i=2,3,\dots,q;$
$P_{i}=C_{i}\oplus E_{K}\left(Y_{i}\right),\quad i=1,2,\dots,q-1;$
$P_{q}^{\ast}=C_{q}^{\ast}\oplus MSB_{u}\left(E_{K}\left(Y_{q}\right)\right).$

Результатом данного этапа является открытый текст $P=P_{1}\|\dots\|P_{q}^{\ast}.$
В том случае если шифртекст $C$ равен пустой строке, то открытый текст $P$ также полагается равным пустой строке.
В результате своей успешной работы функция $MGM-Decrypt$ возвращает набор данных $(A,\,P)$. В противном случае функция возвращает сообщение об ошибке.
